# 清理推理过程泄漏

推理过程泄漏，是指其视角是**写它的那次会话**、而不是仓库的文字：它引用只有那次会话能看到的产物，叙述变更而不是状态，或与一个已经离开的评审人争论。

修复**不只是删除**——当一段文字承载事实子句时，把每个子句改写成在当前位置能独立成立，然后删掉周围的"过程"。一个事实子句都不承载的（审计代号、控制流叙述）直接删除。**必备背景**：[`prose-standard`](../prose-standard/SKILL.md) 拥有本技能套用的"完整命题"规则。它是指导，不是脚本。

## 唯一的判据

对每段可疑文字问：**一个在当前位置、看不到任何会话记录、PR 线程或未提交草稿的读者，能不能解析每一个引用、验证每一条断言？** 不能，就从仓库的视角重述存留下来的事实并删掉其余。能，它就不是泄漏，无论听起来多像历史——但"可解析"只过得了本技能的关：在当前状态表面（README、docs、注释）上，一个可解析的变更故事**仍然**是变更叙述，按第 3 类送回它被允许的归属处。

## 分类

1. **只存在于设计过程的引用**：`(决策7)`、`(审计 C2)`、`设计 §4.7`、`计划 §1.4`、阶段标签（`T4`、`P-I`）。若该决策有一个已提交的拥有者，按名字与路径引用它；否则删掉引用并把事实子句重述成独立成立。
2. **栈与 PR 视角**：本栈里更靠后的 PR、本 PR 新增、上一个提交。陈述发布的机制或扩展点；推迟的工作移到 TODO 标记、issue 引用，或一条只含 `intent.md` 的链（见 [`changes/README.md`](../../../.changes/README.md)）。
3. **变更叙述与版本戳**：以前、不再、旧的 X，以及指示性戳记（v1、这次裁掉、今天、现在对比过去）。陈述当前行为；一个固定的回归变成现在时的反事实（没有 X 就会 Y），永远不是仓库历史（以前会 Y）。
4. **评审编排**：评审时被否、评审人确认了、草稿序号。把存留下来的决策与理由写成朴素事实；删掉谁在何时说的。
5. **对着评审人的辩护**：这个转换是安全的因为它只是……、这是对的因为……。一段论证自己正确性的注释在对评审人说话，不是对维护者。要么陈述使代码安全的不变量，要么在代码已经表明时删掉注释。
6. **复述与推导过程**：控制流叙述（先 X 再 Y）、测试走查、显然分支的证明。删掉；只保留不显然的约定或不变量。
7. **犹疑与规划残留**：现在这样大概没问题、应该够了、没有标记的推迟。升级为 TODO 或 FIXME，或重述成真正的边界；删掉犹疑。
8. **写作语言滑入**：在一种语言的文字里混入另一种语言的未翻译片段。

## 什么不是泄漏

无依据的引用清理在两个方向都会失败：删掉持久引用、留下死引用。下面的保留规则照写执行：

- **issue 引用**：`#1470`、issue #N 拥有后续，在当前位置可解析；在任何表面都保留。
- **变更链与复盘里已合并的 PR 与 issue 引用**：被文档标准许可的证据。
- **抑制理由**：lint 禁用理由、覆盖率忽略理由、空捕获解释是必需的；修一条错误的理由，绝不删除。
- **现在时反事实的回归钉子**：没有 X 就会 Y、一个朴素的 X 会……。
- **实测边界**：（实测：512 层嵌套约 0.15 秒）里"实测"一词承重。
- **运行时的新旧状态**：旧连接排空后新连接才接受，是运行时生命周期，不是变更历史。
- **在仓库外按其设计可解析的外部引用**：标准章节（如 RFC 9110 §10.1.5）、外部设计稿；章节号禁用针对的是未提交的内部草稿，不是外部标准或拥有自己章节编号的已提交文档。
- **项目口吻与文体形式**：我们作为项目口吻；变更链 `spec.md` 的 `## Alternatives considered` 章节。

## 工作流

1. 按 [`prose-standard`](../prose-standard/SKILL.md) 定范围与排除：要求显式范围；绝不碰 vendor 目录、`.changes/archive/` 与录制的夹具和快照。
2. 先只读审计：用召回探针跑一遍，再逐条语义判断。探针是线索，不是定义——还要不带模式地读范围内最密的文字（模块注释、README、变更链）。
3. 按表面先改拥有者：生成的目录先改源注释或模板再重生成；模型可见字符串的措辞就是行为，标记为需要快照支撑的改动，而不是悄悄改写。
4. 删除任何东西前，枚举该段落的命题（见 prose-standard），并检查过度修正陷阱：把义务修成背书、把假设升格为已发布特性、删掉一个真事实、丢掉出处。
5. 校验：重跑探针，期望只剩被许可的保留；确认每一条剩下的引用在当前位置可解析；对触及的表面跑 `python3 .agents/scripts/check_docs.py`。
