# Plan: 忘记密码的自助重置

## Files

- `accounts/reset.py`（新增）：发起重置、校验令牌、设置新密码三个入口。
- `accounts/reset_test.py`（新增）：令牌过期、重放、探测账号等场景的测试。
- `mail/reset.html`（新增）：重置邮件的模板与链接。
- `docs/accounts.md`：补记重置流程与令牌有效期。

## Order of work

1. 加"请求重置"入口，先固定返回同一句话，不发真实邮件——此时行为对用户不可见。
2. 实现令牌的生成、存储与校验，接上邮件发送。
3. 加"设置新密码"入口，令牌用过即废。
4. 补测试与 `docs/accounts.md`。

## Risks

- "总是返回同一句话"会让用户拿不准邮件是否发出，产品上要配合明确的发送成功提示。
- 令牌表随每次请求增长，需要清理过期令牌，这是新增的运维项。

## Proof

- 单测：令牌 60 分钟后过期；同一令牌用第二次被拒；不存在的邮箱与存在的邮箱返回同一响应。
- 集成测试：走完"请求 → 收邮件 → 点链接 → 设新密码 → 用新密码登录"全链路。
- 实测：客服侧的重置工单从每周几十单降到个位数。
